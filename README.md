# Last Order — Последний заказ

Прототип игры от третьего лица: курьер сражается с зомби на складе, бросая пакеты с заказами.

## Цель

Уничтожить 20 зомби. После зачистки ворота открываются. Выход за ворота завершает забег — появляется экран «Заказ доставлен».

При гибели курьера появляется «Заказ не доставлен». Оба экрана показывают время, количество уничтоженных зомби и оставшиеся сердца. Кнопка «Повторить заказ» перезапускает игру.

## Управление на ПК

- WASD или стрелки — движение.
- Мышь — поворот камеры.
- ЛКМ — бросок пакета; удержание повторяет броски.
- E — подбор аптечки рядом с ней.

## Мобильное управление

Предусмотрены левый джойстик движения, правый джойстик камеры и кнопки «БРОСОК» и «ПОДОБРАТЬ».

Для предпросмотра в редакторе перед запуском Play включите `Canvas → Mobile Input Mode → Preview In Editor`. Для обычной игры на ПК этот флажок выключен.

При наличии датчика ориентации движение также управляется наклоном устройства. Нейтральное положение определяется автоматически после стартового отсчёта. Клавиатура и джойстик имеют приоритет над наклоном.

## Игровые параметры

- 20 зомби за забег, до 10 одновременно.
- Зомби погибает от трёх попаданий пакетом.
- У курьера 10 сердец; удар зомби отнимает одно.
- Аптечка восстанавливает до трёх сердец. При полном здоровье она не расходуется.
- Время прохождения считается после стартового отсчёта.

## Запуск проекта

1. Установите Unity 6000.0.29f1 и Git LFS.
2. Клонируйте репозиторий с загрузкой LFS-файлов. При необходимости выполните `git lfs pull`.
3. Добавьте папку проекта в Unity Hub и дождитесь импорта.
4. Откройте сцену `Assets/Scenes/Warehouse.unity`.
5. Нажмите Play, затем START во вкладке Game.
